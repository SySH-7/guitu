# 验证范围与版本对应

## 版本

- 功能及备份格式基于 Android 0.2.2；界面视觉参考 Android 0.3.1。
- 平台留档版本 `v179215220644`，开发者于 2026-10-20 确认审核通过。此记录不代表已发布上线。
- 获审构建 SHA-256 与公开业务文件 SHA-256 见 [version-reference.json](version-reference.json)。
- `src/app.js`、`core.js`、`cloud-codec.js`、样式、模板、基础目录和 `build.py` 均原样复制。本次整理没有变更已部署版本。
- 公开副本只去除生产地图 AK 和私有城市坐标表；构建仍可运行，但不能宣称默认公共构建与获审 HTML 逐字节相同，也不能保证首次城市定位速度一致。

## 真实平台验证的边界

此前在已登录 Safari 平台预览中确认过正常写入、回读、删除及载荷体积造成的 HTTP 414；读取保护版本还验证过启动读取和摘要查看。不能把某一桌面浏览器成功当作所有手机账号、白名单和网络的保证。

30,000 字节是本应用针对 GET 上传网址长度设置的保守上限，并非平台公开容量。5 次/周使用应用与云端可见计数，不具备强服务端防绕过保证。当前没有自动文本安全审核代理。

平台 SDK 和地图服务可能变化；公开源码、测试通过或曾获审均不等于平台永久支持。重新部署者应在自己的贴吧应用中核对身份、地图权限、云端读写和真机布局。
